# 0916 확장 검증 — 2026-09-16

검증 빌드: `Expansion0916g/ObjectHead.exe` (Unity 6000.4.0f1 Windows).

## 통과

- 오디오: WAV BGM 연결, 타이틀 재생, 설정 슬라이더 0.37 반영 및 0 음량 반영, 전투 진입 시 정지, 타이틀 복귀 시 재생, 볼륨 유지, 오디오 서비스 중복 없음.
- Throw/Impact WAV 및 재생 호출 제거. 두 파일은 프로젝트 밖 백업에 보관하고 빌드에 포함하지 않음.
- 캐릭터: 6종 스폰, 18개 머리와 스킬 ID, 과대 머리 크기 회귀 검사.
- 공용 머리: 7종 필드 표시 크기, 카탈로그 그림 연결, 인벤토리 그림, 실제 장착 그림 일치. 기존 공격 폭탄·날개·구름은 새 아틀라스를 쓰는지 별도 확인.
- 회복: 자신·아군·적군 및 최대 HP 상한. 철모 피해 흡수, 자석 인력/척력 방향. 구름 지형 충돌과 파괴.
- 편성 목록: 가상 80항목 검색/역할 필터. 이것은 실제 80종 캐릭터가 구현됐다는 뜻이 아님.
- 섬 3개 × 모드 3개, 스폰 시드 216개, 개인전/팀전 승패 처리.
- Nakama 두 클라이언트: 신규 캐릭터 편성 후 리볼버 공습, 발사 명령·턴·스냅샷·지형 변경 수신. 호스트/클라이언트 모두 PASS.
- 이 검증에서 실행한 모든 테스트 프로세스 정상 종료. 오류로 테스트 흐름이 중단되어도 제한 시간 후 종료하는 보호 추가.

## 검사 중 구분한 문제

제한된 검사 환경에서는 Unity 설정 저장 접근이 거부되어 첫 오디오 검사가 실패했다. 일반 실행 권한으로 재검사하여 전 항목 통과했고 원래 BGM 설정은 복원했다. 따라서 이 실패를 사용자가 경험한 볼륨 문제의 확정 원인으로 해석하면 안 된다. 여러 실행본은 서로 다른 오디오 소스를 가지므로 한 실행본의 슬라이더로 다른 프로세스 소리까지 제어하지 않는다.

## 아직 검증/구현이 남은 범위

공용 머리의 네트워크 획득·사용·인벤토리·철모 상태 권한 처리, 공개 방 목록, 외부 서버 배포, 4인 장시간 실전, 재접속/호스트 이탈, 모든 신규 스킬의 다중 클라이언트 결과 일치는 완료되지 않았다. 전체 출시 품질 완료를 의미하지 않는다.
