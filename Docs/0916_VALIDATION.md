# 0916 검증 기록

검증 환경: Windows / Unity 6000.4.0f1 / 개발용 Nakama.

## 통과한 검사
- Windows 플레이어 빌드: 성공(약 168 MB, 디렉터리 합계와 차이 있을 수 있음).
- 활성 씬의 글꼴 및 필수 UI 참조 검사.
- 로컬 실행: 새 맵 3종 × 모드 3종 = 9개 조합.
- 각 조합에서 24개 시드로 지정 스폰 배치(총 216회): 캐릭터 수, 생존 상태, 시작 높이 편차 검사.
- 3인 캐릭터 규칙 없음 검사.
- 2대2 양 팀 턴 교대, 아군 1명 생존 시 경기 유지, 팀 승리 판정.
- 2인/4인 개인전 승리 판정.
- 한국어 타이틀 / 캐릭터 선택 / 전투 화면을 실제 게임 렌더러로 출력하여 확인. 숨김 창의 검은 화면 캡처 대신 테스트 전용 오프스크린 렌더 요청 사용.
- Nakama 실접속: 2인 개인전(2개 클라이언트), 4인 개인전(4개), 2대2(4개). 각 참가자의 로비·선택 준비·전투 진입, 턴/발사/지형 작업 메시지 수신 검사.

## 해석의 한계
- 216회 검사는 스폰 안전성과 높이만 검증. 체감 공정성, 집중 공격률, 승률을 검증한 것은 아님.
- 네트워크 smoke는 메시지 전달 검사. 최종 지형 해시, 전체 물리 상태, 공용 머리의 최종 일치까지 증명하지 않음.
- 로컬 프로세스 여러 개를 사용했으므로 인터넷 지연/손실 환경이나 외부 접속 검증이 아님.
- 장시간 사람 간 플레이와 외부 서버 배포를 마쳐야 출시 후보로 판단할 수 있음.

원본 검증 로그와 캡처는 작업 폴더 Work에 보관. 초기 실패 로그(UI 패널 참조 누락, 긴 테스트 닉네임 중복)도 남겨 두었으며 수정 후 재검사한 결과와 구분함.
