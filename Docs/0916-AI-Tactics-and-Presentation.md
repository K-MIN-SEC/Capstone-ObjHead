# 0916 AI / 전투 연출 강화

## 범위

중앙 서버 배포와 웹 대응은 보류한다. 로컬 AI와 훈련장, 기존 설치형 클라이언트의 연출을 개선한다.
Worms의 포격 전투 가독성을 참고하지만 원작 소스, 이미지, 음원은 가져오지 않는다.

## AI

- 실제 SkillFireController의 발사 속도·중력·생성 위치를 이용한 저각/고각 탄도 탐색.
- 물리 충돌과 픽셀 지형을 검사하여 벽을 관통하는 가상 명중을 점수로 인정하지 않음.
- 적에게 줄 피해, 처치 가능성, 자신/아군 피해, 실제 부족한 체력, 적 치유를 함께 평가.
- 빈 곳 치유, 사거리 밖 가상 명중, 포획 중인 대상에 대한 공격 점수를 배제.
- 쏠 수 있는 유효한 공격이 없으면 먼저 이동하고 다시 탐색. 그래도 없으면 턴 종료.
- 공격 뒤 허용된 잔여 이동 시간에는 가까운 예상 폭발 지점으로부터 퇴각.
- 초보/일반/프로는 탐색 정밀도와 기존 조준 오차가 다름. 피해량이나 사거리를 몰래 늘리지 않음.
- 탐색을 여러 프레임에 나누고 시간 예산을 제한. 일반 게임 프레임에서 무제한 물리 시뮬레이션하지 않음.

한계: 전역 길찾기, 여러 턴 뒤의 지형 예측, 공용 인벤토리의 전략적 사용은 이번 탐색에 포함하지 않음.
연쇄 폭발은 근사 점수로 비교하며 미래 적 이동은 정확히 알지 못함.

## 연출

- 신규 투명 효과 아틀라스: 치유, 자력, 물, 증기, 유리 파편, 흙 파편, 자물쇠, 탄환, 경고 표식.
- 개별 Prefab에서 크기 곡선·투명도·회전·상승·지속시간을 편집.
- 공습 / 치유 보급 / 자물쇠의 지연 착탄에 예고 표식 연결.
- 공습은 실제 폭탄 도착에만 폭발 효과 표시. 예고 때 폭발을 먼저 재생하지 않음.
- 지표 장판 높이 0.3 → 0.55, 지형 겹침 비율 0.22. 실제 피해 범위는 유지.
- 시각 효과는 판정과 분리. 전용 계산 서버에서 시각 효과를 생성하지 않음.
- 사운드는 이번 범위에서 추가하지 않음.

## 카메라 / 맵

- 캐릭터 조작 시 기본 시야 5.5, 비행 시 7.5~10으로 부드럽게 확대.
- 투사체 진행 방향 미리 보기, 실제 명중 지점 잠시 유지, 짧은 감쇠 화면 흔들림.
- 수동 카메라 조작 중 자동 확대/명중 추적을 억제하며 수동 줌 값을 기억.
- 다음 턴에는 다음 캐릭터로 부드럽게 복귀.
- 3개 섬 지형 가로 폭 48 → 60. 높이·동굴·섬 콘셉트 유지, 스폰 X도 같은 비율로 변환.
- 이 수치는 원작의 내부 수치를 복제한 것이 아니라 우리 이동/사거리/캐릭터 단위에 맞춘 초기값.

## 에디터에서 수정할 곳

- `Assets/Resources/ObjectHeadAITuning.asset`: 탐색 수, 시간 예산, 아군 피해 페널티, 퇴각 시간.
- `Assets/Resources/ObjectHeadCameraTuning.asset`: 자동 시야, 진행 방향 미리 보기, 흔들림 (0으로 끌 수 있음).
- `Assets/Resources/ObjectHeadPresentation.asset`: 스킬별 효과 Prefab, 표식, 장판 크기/겹침.
- `Assets/Prefabs/Effects/*`: 실제 효과 모양과 재생 곡선.
- `Assets/GameData/Maps/*.asset`: 픽셀 지형 좌표와 크기. 변경 후 Bake Terrain Texture.
- 씬의 스폰 마커: 직접 이동 가능. 기본 빌드는 위치나 위 프리셋을 재생성하지 않음.

## 새 이미지 출처

내장 image_gen으로 생성한 프로젝트 전용 신규 아트. imagegen 스킬의 참조 이미지 확인 및 알파 검사 절차 사용.
저장 위치: `Assets/Art/Presentation/TacticalEffects.png`.
참조: 기존 `FlatEffects.png`, `WorldEffects.png` (스타일 참조만).
최종 프롬프트: 투명 배경의 3×3 균등 아틀라스. 굵은 검은 손그림 외곽선, 평면 만화색, 작은 화면에서도 읽히는 단순 실루엣.
첫 줄: 민트 치유 십자/반짝임, 빨강·파랑 자력 곡선, 푸른 물방울 폭발.
둘째 줄: 회백색 증기, 흰색·청록 유리 파편, 갈색 흙덩이 파편.
셋째 줄: 황동 자물쇠, 노랑·아이보리 총구 섬광, 빨강 주황 경고 조준 표식.
각 셀 투명 여백 15%, 글자/격자/배경/블룸/워터마크 없음. 새 캐릭터나 무기를 포함하지 않음.

## 검증 범위

Tactics smoke는 탄도 해, 벽 충돌, 아군 피해 및 적 치유 점수, 스킬별 효과 누락, 예고 표식,
효과 수명 정리, 맵 폭을 검증하고 실제 Unity 렌더러의 화면을 저장한다.
기존 AI / CombatFix / Polish / Expansion / Release 회귀 테스트도 함께 수행한다.
중앙 서버 접속과 실사용자 장시간 테스트는 이번 작업의 완료 주장에 포함하지 않는다.

### 2026-09-16 실행 결과

- Windows 최신 빌드 성공 (`Builds/Latest/ObjectHead.exe`).
- AI: 실제 발사, 난이도/구성, 사람 입력 차단 통과. 발사 검사는 명시적으로 사거리 안에 둔 표적으로 수행했으며 장거리 길찾기 보장은 아님.
- Tactics: 탄도/엄폐/아군 피해/적 치유 점수, 26개 효과 연결, 3개 예고 표식, 효과 정리 검사 통과.
- CombatFix: 공용머리 낙하/충돌 제외, 턴 끝 치유/공습/포획과 양 진영 판정 통과.
- Polish / Expansion: AI 구성 저장/실행, 장판 종횡비·회전, 6캐릭터/18스킬머리/8공용머리 회귀 검사 통과.
- Release: 맵·모드 9개 조합, 스폰 시드 216개, 타이틀/로비/승리 검사 통과. 이는 스폰 유효성 검사이며 플레이어 체감 공정성의 확정은 아님.
- 실제 렌더러에서 `tactical-effects.png`, `landing-warnings.png`, `slope-zone.png` 화면 확인.
- 자동 검사는 장시간 사람 대전, 네트워크 지연, 다양한 PC 성능 검사를 대체하지 않음.
