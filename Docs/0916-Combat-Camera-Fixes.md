# 0916 전투·AI·카메라 보완 (2026-09-16)

## 변경

- 리볼버 3번 공습: 피해 반경 1.35 → 2.1. `ObjectHeadData.xlsx`의 `skill.revolver.3.radius`에서 수정.
- 리볼버 2번 치유 보급, 리볼버 3번 공습, 자물쇠: 탄착 위치에 표식을 남기고 잔여 이동 종료 후 낙하/효과를 처리. 이후 피해를 정산하고 다음 턴으로 진행.
- 치유 보급은 현재 기존 빨간 포션 스프라이트를 낙하 보급으로 사용. `ObjectHeadPresentation`의 Healing Supply Sprite/Size로 교체 가능.
- 아군·적군 모두 치유/공습/포획 범위에 포함.
- 공용머리의 바닥 충돌과 줍기는 유지. 투사체와는 충돌하지 않으며, 지형이 파괴되면 고정을 해제하고 낙하.
- AI가 안전한 발판을 확인하며 사격 위치로 이동. `ObjectHeadContent`의 AI movement 항목으로 이동 시간, 거리, 지형 탐색 거리 등을 조절.
- 사용자 입력과 시뮬레이션 권한 분리. AI/다른 플레이어 턴의 이동·조준·차징·스킬 선택·턴 종료 입력 차단. 전용 서버의 발신자/턴/캐릭터 검증 유지.
- AI 편성: 랜덤 또는 직접 선택. 수동 선택은 랜덤 전환 후 돌아와도 보존.
- 캐릭터 6종의 고유 머리 18개와 공용머리 8종의 표시 크기 정규화. 디자이너가 설정한 프리팹 위치/기준 크기는 유지.
- 경사면 장판 그림을 가로로 찌그러뜨리지 않고 지형 기울기에 맞춰 배치.
- 카메라: 마우스 가장자리 이동, Home/I로 현재 캐릭터 보기, 휠 확대·축소, P 전체 보기. O/K/L/; 키와 가운데 버튼 드래그는 보조 조작. 우클릭 드래그는 제거.
- 걷기: 캐릭터별 연속 재생 시계와 이동 속도 연동. 짧은 지면 접촉 손실에 점프/착지 모션이 반복되지 않도록 유예 적용.
- HUD 상태 표시 갱신 빈도를 제한. 차징 막대는 매 프레임 갱신.

## 검증

`Builds/Latest/ObjectHead.exe`에서 별도의 테스트 프로세스로 실행 후 종료.

- AI: 실제 이동 약 1.88 월드 단위 후 공격. 키보드 이동/점프/조준/차징/스킬/턴 종료 입력 주입 및 네트워크 좌석 권한 검사 통과.
- CombatFix: 기존/새로 생성된 공용머리에 대한 투사체 통과, 지형 파괴 후 낙하, 치유/공습/포획 지연 처리와 양 진영 적용 통과.
- Polish: 직접 선택한 AI 편성 보존과 경기 진입, 아군 AI 편성, 경사 장판의 비율/회전 통과. 실제 렌더 캡처 확인.
- Expansion: 6 캐릭터, 18 고유 머리, 8 공용머리의 교체 크기 및 기존 전투 기능 통과.
- Release: 9 맵/모드 조합, 216 스폰 시드, 타이틀/로비/승리 조건 통과.

## 검증 범위와 남은 확인

- 서버는 실행하지 않았음. 다중 클라이언트의 실제 네트워크 지연/낙하 연출 동기화는 이번 검증에 포함하지 않음.
- 영상에서 기존 카메라 이동을 확인하고 코드의 입력 처리와 애니메이션 전환을 보완. 다양한 PC에서 걷기/카메라 조작의 주관적인 체감 평가는 별도 필요.
- 출시 품질 전체를 보증하는 검증이 아니라 위 회귀 항목에 대한 결과임.
