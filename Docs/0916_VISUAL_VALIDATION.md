# 화면 개편 검증 기록

## 통과한 검사

- Unity 6000.4.0f1 Windows 빌드 성공.
- 실제 게임 렌더링으로 타이틀, 편성 화면, 3개 맵의 2인/4인 개인전/2대2 화면 확인.
- 9개 맵·모드 조합, 총 216개 스폰 시드의 동일 시작 높이 및 개인전/팀전 승리 조건 검사 통과.
- 전구·씨앗·폭탄 각 3개 스킬을 실제 발사했고, 대응하는 9개 연출 프로필 생성 및 화면 캡처 검사 통과. 이는 모든 공격 상황의 게임 밸런스 검증을 의미하지 않는다.
- 로컬 Nakama에서 2인, 4인 개인전, 4인 2대2 클라이언트의 매칭, 준비, 시작, 공격 명령 및 지형 명령 수신 검사 통과. 지형 최종 마스크가 서로 같은지는 별도 검사 대상이다.
- 타이틀에서 버튼을 직접 눌러 편성 확정 후 게임에 진입했다. 줄어든 HUD와 타이머 표시를 실제 창에서 확인했다.

## 휠 수정

- 이벤트인 휠 입력에 프레임 시간을 곱하던 문제를 제거했다.
- 실제 화면 조작에서 Unity Input System의 기본 정규화(-1~1)를 Windows 원시 값(-120~120)으로 다시 나누는 문제를 추가 발견했다. 현재 설정이 정규화인지 검사해 중복 나눗셈을 하지 않도록 수정했다.
- 한 칸 확대는 시야 크기 ×0.84, 반대 방향은 ÷0.84. 범위는 Inspector에서 조정할 수 있다.
- 최종 입력 수정 빌드에서 실제 휠 한 칸 확대, 반대 방향 복귀, 다섯 칸 축소를 화면으로 확인했다.
- 1280×720 실제 게임 창에서 최대 축소 시 배경 테두리가 보이지 않는 것을 확인했다. 배경 보정 후에도 9개 맵·모드, 216개 스폰 시드 검사를 다시 통과했다.
- 에디터 검사에서 정규화 입력 1과 원시 입력 120이 같은 한 칸으로 처리되며, 시야 크기 7.5 → 6.3 → 7.5로 복귀함을 확인했다.

## 출시 전 남은 검증

외부 서버 운영, 지형 최종 마스크 일치, 공용 머리 상태의 네트워크 일치, 재접속/호스트 종료 처리, 장시간 대전, 실전 맵 승률은 아직 완료되지 않았다. 이 작업은 화면·연출 개선과 관련 회귀검증이지 출시 승인판정이 아니다.
