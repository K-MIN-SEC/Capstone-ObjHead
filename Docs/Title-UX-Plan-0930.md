# 타이틀 UI·UX 구성안 (2026-09-30)

이 문서는 구현 현황이 아니라 다음 타이틀 개편의 화면 설계 기준이다. 기존 손그림·검은 외곽선 아트는 유지하고, 읽기 어려운 반투명 패널과 좁은 버튼을 정리한다.

## 화면 흐름

```text
타이틀
├─ 게임 시작
│  ├─ 빠른 시작 → 인원/룰 선택 → 매칭 대기
│  ├─ 방 찾기 → 공개방 목록 / 방 코드로 참가
│  ├─ AI 대전 → 인원/팀/AI 난이도/랜덤·선택 구성 → 로비
│  └─ 훈련장 → 맵·캐릭터 선택 → 훈련
├─ 방 만들기 → 인원/룰/공개·비밀/비밀번호 → 로비
├─ 설정 → 화면/음량/언어 → 적용·확인
└─ 종료
```

## 공통 레이아웃

- 첫 화면은 로고와 섬 배경, 오브젝트헤드 대표 아트를 드러낸다. 왼쪽에 하나의 선명한 메뉴 영역만 두고, 제목을 패널로 가리지 않는다.
- 하위 화면에서는 큰 타이틀 로고를 숨기고 화면 제목·설명·뒤로 가기를 같은 헤더 위치에 둔다. 뒤로 가기는 우측 상단이 아닌 좌측에 고정한다.
- 주 행동은 주황색 한 개, 보조 행동은 청록색으로 통일한다. 같은 위계의 버튼은 너비·높이·정렬을 같게 한다.
- 입력란, 선택 항목, 도움말, 오류는 각각 충분한 간격을 갖는다. 비밀번호 입력란이 방 만들기 버튼과 겹치면 안 된다.
- 전환은 짧은 페이드/슬라이드만 사용한다. 입력 중 또는 매칭 중에는 중복 클릭을 막되 취소와 뒤로 가기는 항상 찾을 수 있게 한다.

## 화면별 정보

| 화면 | 우선 보이는 정보 | 주 행동 / 예외 상태 |
| --- | --- | --- |
| 타이틀 | 게임명, 게임 시작, 방 만들기, 설정, 종료 | 게임 시작만 가장 강하게 강조. 닉네임은 온라인 진입 때 요청 |
| 게임 시작 | 빠른 시작, 방 찾기, AI 대전, 훈련장 | 네 선택지 모두 같은 크기와 간격 |
| 빠른 시작 | 2인 개인전 / 4인 개인전 / 4인 2대2 | 비밀방은 매칭 후보에서 제외. 대기 중 취소 가능 |
| 방 찾기 | 공개방 목록의 방 이름·모드·인원·맵·입장 가능 여부 | 목록 행 전체를 누르면 참가. 비밀방은 코드·비밀번호로 별도 참가. 빈 목록·연결 실패 상태 구분 |
| 방 만들기 | 모드, 공개·비밀, 비밀 선택 시 비밀번호 | 생성 버튼은 패널 하단 고정. 입력 오류는 해당 필드 아래 표시 |
| AI 대전 | 플레이어/AI 좌석과 팀, 난이도, 랜덤·직접 선택 | 4인전은 좌석별 2캐릭터를 명시. 팀전은 팀 색·묶음으로 구분 |
| 설정 | 해상도, 창 모드, 언어, BGM/SFX 수치 | 변경 값을 즉시 읽을 수 있어야 함. 화면 변경 후 제한 시간 내 확인하지 않으면 복구 |

## 확인 기준

- 1280×720, 1600×900, 1920×1080 및 창/테두리 없는 창/전체화면에서 겹침·잘림이 없다.
- 한국어와 영어 모두 긴 문구가 버튼이나 입력란 밖으로 넘치지 않는다.
- 마우스와 키보드/패드로 동일한 경로를 이동할 수 있고 현재 포커스가 눈에 보인다.
- 공개방이 0개일 때 빈 화면이 아닌 설명과 새로고침이 표시된다. 연결 실패와 방이 없는 상태는 다른 문구다.
- 방 목록에서 팀·인원과 입장 가능 여부를 펼치지 않고도 읽을 수 있다.
- 모든 하위 화면에서 뒤로 가기 위치와 동작이 일관된다.
