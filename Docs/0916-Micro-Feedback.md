# 작은 전투 반응과 UI 폴리시

## 변경 범위

- 실제 지형 픽셀이 제거될 때만 흙 파편/먼지 발생. 동일한 파괴 명령 재적용으로 지형이 바뀌지 않으면 효과도 재생하지 않음. 구름 위주 파괴에는 흙 파편 생략.
- 걷기 거리/간격에 따른 발밑 먼지, 점프 이륙과 낙하 착지 반응. 경사면의 순간 접촉 끊김에는 유예 시간을 적용. 정지/순간이동을 발걸음으로 보지 않음.
- 발사 잔상, 몸체만 움직이는 작은 반동, 피격 반짝임, 캐릭터 입수 물보라.
- 타이틀/게임 내 버튼: 호버/선택/눌림 반응. 클릭 처리 및 레이아웃은 유지. 창 포커스 상실/비활성화 시 눌림 상태 복구.
- 체력 막대는 수치 변경을 부드럽게 따라감. 실제 HP 및 피해 정산 시점은 변경하지 않음.
- 턴 변경 시 기존 턴 안내 문구에 짧은 크기 강조. 새로운 팝업이나 입력 지연 없음.

## 편집 위치

- `Assets/Resources/ObjectHeadMicroFeedback.asset`: 전체 효과 활성화, 동시 입자 수, 프레임당 생성 제한, 보이는 화면 여백, 효과별 그림/색/개수/크기/속도/중력/수명, 걸음/착지 기준과 반동 강도.
- `Assets/Prefabs/UI/ObjectHeadTitle.prefab` 및 각 맵 씬의 Button에 붙은 `ObjectHeadButtonFeedback`: 선택/눌림 배율과 반응 속도. 컴포넌트를 끄면 원래 크기로 복귀.
- 각 맵 씬의 `ObjectHeadBattleScreen > HUD motion`: 체력 막대 보간, 턴 안내 강조 시간/강도.
- 명시적 설치 도구 `Object Head > Visuals > Install Micro Feedback`만 최초 구성. 일반 빌드는 사용자 편집 값을 덮어쓰지 않음.

## 안전/성능

- 기존 TacticalEffects 그림을 Sprite 참조로 재사용. 새 외부 이미지/음원, 게임 판정용 오브젝트를 추가하지 않음.
- 씬 시작에 기본 160개의 SpriteRenderer를 재사용하도록 준비. 프레임당 최대 48개의 입자만 내보내며 초과 효과는 생략. 화면 밖 효과도 생략. 풀 크기 변경은 씬을 다시 열 때 적용.
- 입자에 Rigidbody/Collider 없음. 시각용 난수는 별도의 System.Random을 사용하여 게임 난수열에 영향 없음.
- 전용 계산 서버에서는 효과를 생성하지 않음. 지형 동기화 명령을 로컬에서 적용할 때 시각 효과만 표시하며 추가 네트워크 이벤트를 전송하지 않음.
- 씬 종료 시 풀 전체 정리. 사운드, 서버 실행/배포, 전투 규칙과 밸런스는 변경하지 않음.

## 검증

`-objectHeadMicroSmoke`는 실제 파괴/중복 파괴, 실제 착지/정지, 풀과 프레임 예산, 게임 난수 독립성, 효과 끄기, 씬 해제, 버튼 호버/원복을 검사한다. Unity 렌더러 화면은 `Work/fix-captures/micro-terrain.png`, `micro-details.png`에 저장한다.
